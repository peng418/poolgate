登录授权式

扫码 / 浏览器点一次授权，凭证自动续期

适用：编程助手 / IDE 类平台 —— QoderCN · TraeWork · WorkBuddy · 千问办公 · 腾讯 CodeBuddy · GitHub Copilot · Windsurf · Kiro · Gemini CLI …
好处：不用 key、协议原生支持工具调用（能给 Studio / Claude Code 干活）

API Key 式

去官网注册后创建一串 key，填进来即可

适用：官方 API —— Google AI Studio · 阿里百炼 · OpenRouter · DeepSeek · 智谱 GLM · 火山方舟/豆包 · 智谱 · MiniMax · SiliconFlow …
好处：配置级、立刻可用、免费额度明确
